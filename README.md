# Libre AI Practice Workbench

Learn through practice with AI while understanding the sources you use and the work you have done yourself. This proposed product is for learners who want a clear exercise, room to try things and a way to reflect on what they learned.


## Intended uses

- Follow an activity with a stated learning goal, source material and instructions.
- Distinguish your own work from suggestions generated by AI.
- Review the result against visible completion criteria and identify what to practice next.

The intended learning experience excludes hidden scoring or scoring for human-resources decisions.

**Today:** this repository documents the proposed product; no usable application is available here yet.
