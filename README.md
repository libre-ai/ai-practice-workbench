# Libre AI Practice Workbench

## Intended use

Help a person practice an AI-assisted activity, inspect the sources behind it and understand what they learned. Exercises support learning without hidden scoring or scoring for human-resources decisions.

## Existing candidates and limits

Earlier sources contain application and local-storage components, with fixture activities. They are candidates for review, not an admitted learning journey. This documentary candidate supplies no executable activity, deployed application or guarantee that personal data stays local.

## Proposed contracts

An activity describes its learning objective, source material, instructions and completion criteria. A practice record distinguishes the learner’s work from generated suggestions. Export and deletion describe the actual data affected. These descriptions are proposals; canonical exchange contracts require admission by Contracts.

## Activation criteria

Select and review a real activity and its source rights. Demonstrate a complete browser journey from opening instructions to completing the activity, including failures and accessibility. Verify the actual storage, export, deletion and network behavior. Review the exact application and dependencies before declaring any activity or privacy property available.

The complete journey described above is a criterion for activating the product. A candidate module may be qualified and admitted separately for its own explicit scope, with its own consumer and evidence. Neither that module admission nor the documentary existence of this repository requires a complete Missions journey or completion of other future products.
